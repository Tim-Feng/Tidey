Tidey is a terminal-first IDE for Claude Code and Codex: persistent workspaces, an editor, a browser and a file tree on one desk — and the same desk on your iPhone with Tidey Remote.

One window, nothing floating.

Every region sits on the same low-contrast surface. Hairlines and short pull bars carry the hierarchy, so the content — not the chrome — is what you look at.

Terminal and editor tabs are outlined like index cards; the one you are reading sits forward and joins the pane below it. Editor and browser tabs share one strip, grouped by small Code and Web tags.

  • Workspaces on the leftEach card is one project with its own tmux session — name and live status only. ⌘1–⌘9 switches.
  • Paper tabsOutlined like index cards; the focused tab comes forward. No glowing underline to find.
  • Code / Web group tagsEditor and browser tabs live in one strip, grouped by compact tags instead of separate toolbars.
  • Short pull barsPanes resize from a small grip at the boundary — no full-height rails cutting the window. Double-click a pull bar to restore that pane’s default size.
  • File tree and Monaco editor⌘-click any path in the terminal to open it beside the shell, with syntax highlighting.

Built for agents that run for a while.

Tidey tracks what every CLI agent is doing and tells you when it needs you — in the sidebar, in macOS notifications, and on your phone.

Works with any CLI agent. Tidey is a fork of iTerm2 — native Objective-C and Swift, no Electron.

Running

The agent is working. Leave the workspace; the card keeps its status while you do something else.

Needs input

Claude Code or Codex stopped to ask you something. The workspace name lights up and the Dock icon carries a badge.

Idle

Finished. Notifications stay unread until you open the workspace, so nothing gets lost across a long session.

Classic, Amber Night, Sakura Fubuki.

The same window in three lights. Every theme keeps the paper tabs, the hairline hierarchy and the status semantics; only the ink changes.

Continue from your iPhone.

  • Pair with a QR code. No account, no cloud login. LAN or Tailscale by default; Cloudflare Tunnel is an optional fallback.
  • Chat with your agents. Claude Code and Codex in a phone-sized chat. Send screenshots or photos straight to the agent.
  • Same terminal history. The live terminal and its retained scrollback, the same as on your Mac.
  • Docs for humans. A reader-friendly view of the documents your agent ships.
